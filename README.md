Overview:
Python-based Smart Campus Assistant developed for the LD4019 Algorithms and Programming Fundamentals module. 
The application uses JSON data storage and a menu-driven interface to support student-focused campus services.

Features:
- View campus events
- Browse and filter study rooms
- Track borrowed items
- Search borrowed item records
- Input validation and error handling
- Backup and restore JSON data
- File handling

Technologies Used:
- Python
- Python datetime module
- JSON
